Como consumir

Os tokens funcionam como CSS puro — use var(--zur-*) em qualquer lugar.

Exportar para Tailwind e Figma

O pacote publica os tokens em outros formatos, gerados do mesmo tokens.css. Os valores do Tailwind apontam para var(--zur-*), então o tema claro/escuro continua trocando em tempo de execução.
