Instalação

Um comando instala e configura o Zuri. Ele pergunta o tema da aplicação e se você quer o modo com IA.

O ng add instala o pacote, importa os tokens, aplica o estilo base do body, adiciona a fonte Nunito Sans e configura o tema. Ele faz duas perguntas:

  • Tema: claro e escuro (segue o sistema, com botão sol/lua), só claro ou só escuro.
  • Modo com IA: instala as skills e os agents do Zuri para Claude Code e Codex (passo 5).

Para não responder nada (CI, scripts), passe as respostas como opções:

O ng add coloca o provideZuriTheme nos providers. Em system o tema segue o sistema operacional até a pessoa escolher no botão, e a escolha fica guardada; um script no index.html aplica o tema antes da primeira pintura, para a página não piscar. Em light ou dark o tema é fixo e o zur-theme-toggle não aparece.

Coloque um único zur-toast-container no componente raiz. Se o tema for "claro e escuro", ponha o zur-theme-toggle na navbar ou na topbar. Para a estrutura de cada página, veja Layouts.

Importe cada componente standalone diretamente onde for usá-lo.

A instalação copia para o seu projeto as skills e os agents do Zuri, para o Claude Code e para o Codex, e coloca as regras de uso no AGENTS.md, que Cursor, Copilot e outras ferramentas também leem. A IA não roda durante a instalação: você a chama depois, no seu editor ou terminal.

Comece por zuri-iniciar (no Claude Code, /zuri-iniciar; no Codex, $zuri-iniciar). Ela olha o projeto, confirma em que situação você está e conduz o resto:

Skill ou agentPara quê
zuri-iniciarPor onde começar: projeto do zero, só backend ou frontend existente.
zuri-layoutEscolhe o layout da página e gera o esqueleto.
zuri-telaCria uma tela a partir das receitas: formulário, tabela, painel, login, lista e detalhe.
zuri-backendLê a API (OpenAPI ou rotas do código) e gera serviços e telas.
zuri-migrarAplica o Zuri num frontend existente, uma tela por vez.
zuri-inventario (agent)Levanta o que trocar num frontend existente, sem alterar nada.
zuri-revisor (agent)Revisa as telas contra as regras do Zuri e aponta o que corrigir.

O material que elas consultam (catálogo da API, regras, receitas, guia de migração) vem dentro do pacote, em node_modules/@juau/zuri/ai/, e acompanha a versão instalada. Para instalar o modo com IA depois, ou atualizar as skills numa versão nova, rode ng g @juau/zuri:ai. Arquivos que você personalizou não são sobrescritos: basta apagar a linha zuri:gerado do arquivo.

Os textos internos dos componentes, como o aria-label do botão de fechar e o "Voltar" da lista e detalhe, vêm em português. Para inglês, ou para trocar só alguns, use provideZuriI18n nos providers da aplicação.
